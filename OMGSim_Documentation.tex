	This document highlights the results obtained for the OMS0108 at the CPPM site. It is a condensed version of the test report document, \textbf{OMS0108\_TR}, which contains a detailed description of the OM test procedure. This document includes two figures and two tables: the first figure shows the visual characteristics of the OM under consideration, while the second figure presents the measured values for the OM. The first table is for the visual inspection of the OM and the second one for the measurements results.
