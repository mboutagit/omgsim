## 1\. Overview

This README was initially written to describe OMGSim. However, it does not contain sufficient information about the LAC-TEL simulation framework, which is built on top of OMGSim.

The following subdirectories contain additional components used by the main program:

- **`LACTELSim/`**: Contains all the functionalities required for the LAC-TEL simulation.
- **`lactel-dataformat/`**: Contains the data formats required to handle data at different processing stages. It is divided into two categories: online and offline.
- **`tools/`**: Contains additional tools used by the simulation, such as the `WaveCatcher` definition and geometry helpers for detector construction.
- **`utils/`**: Contains utility functionalities, including the `BLogger` class for logging and `dbRoutines` for database communication.

## 2\. Dependencies and External Libraries

The program also relies on the following external libraries:

- [CLI11](https://github.com/cliutils/cli11): A command-line parser for C++11.
- [MySQL Connector/C++](https://github.com/mysql/mysql-connector-cpp): Used for database connectivity, particularly to retrieve online parameters and configuration settings. Please provide the database file path in the CMakeList to compile in this structure:

```
[your-database]
host=host
user=username
password=pwd
port=3306
database=your-database
```

A definition file is provided to build a container environment in which all required dependencies are installed.

[GitHub repository](https://github.com/mysql/mysql-connector-cpp.git)

## 3\. How to Run

The main executable is `OMGSim`. From its directory, the simulation can be launched using:

```bash
./OMGSim -fa script/lactel.mac -dl 4
```

### 3.1. Available Command-Line Options

The program uses command-line arguments to configure its execution. Each parameter is associated with a predefined keyword, prefixed with either `-` or `--`.

The currently available options are:

| Option                 | Description                                                                                                               |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `-d, --debug`          | Enables debug mode. A non-zero value activates debugging (default: `false`).                                              |
| `-s, --session`        | Activates session mode.                                                                                                   |
| `-ka, --keep-all`      | Keeps track of all event steps in the output file. This option is becoming obsolete with the introduction of `LACTELSim`. |
| `-fa, --full-analysis` | Enables full analysis. This option is currently obsolete in the LAC-TEL framework.                                        |
| `-evt`                 | Generates an `.evt` file containing detailed hit information.                                                             |
| `-evtf`                | Specifies the output filename for the `.evt` file.                                                                        |
| `-r, --run`            | Specifies the Geant4 run number.                                                                                          |
| `-dl`                  | Sets the debug level used by the logger.                                                                                  |

> **Note:** The code is still under active development. Some options and functionalities are obsolete and will be removed in upcoming versions as part of the code cleanup.

## 4\. Additional Programs

The `BPostAnalysis/` directory contains dedicated programs for testing and validating various `LACTELSim` components and functionalities.

The available programs are:

- **`BDAQProcessor`**: Processes the output generated by OMGSim and applies DAQ processing. It takes a ROOT file containing the current `DetectedEvent` and `Event` class structures as input. Run `BDAQProcessor --help` to display the available options.
- **`BDetector`**: Generates predefined LAC-TEL detector configuration files using the `BLactelDetector` class. Users can modify the implementation to generate more specific detector configurations.
- **`BFlux`**: Visualizes the flux used in the simulation and checks the integrity of the input data.
- **`PostAna`**: Processes real-data and Monte Carlo (MC) files and generates high-level analysis plots.

For any of these programs, run the executable with the `--help` option to display its available command-line arguments and usage instructions.

# Documentation

The online documentation can be accessed here: https://simulation.pages.km3net.de/omgsim/html/.

Locally, the doxygen documentation is provided in the folder `documentation` (including installation guides).
It is easier to use it at your local machine.

## Compile with:

```
cd [your checkout path]/trunk
doxygen documentation/config.dox
cd documentation/latex
make
```

## Open (on linux):

```
firefox documentation/html/index.html
gnome-open latex/refman.pdf
```

## Open (on Mac):

```
open documentation/html/index.html 
open latex/refman.pdf
```

Note that the Doxygen needs to be installed. On MacOS type:

```
brew install doxygen  
```
